ZeMobida

An adventure and decision-driven game where your conversations have consequences.

🚧 Project in development

ZeMobida is an open-source video game developed with Godot
.

The project is still in an early stage of development. Many of its mechanics and content may change as the game evolves.

🎮 The Game

In ZeMobida, you will explore a world populated by characters you can interact with, make decisions, and discover different situations.

Conversations are not simply text: your decisions can change the game state, affect your inventory and experience, and unlock new possibilities.

The goal is to build an experience where the player's decisions matter.

✨ Features
💬 Branching dialogue system.
👥 Non-player characters (NPC).
🎒 Inventory system.
⭐ Experience and levels.
🔀 Decisions and conditions.
🌍 Explorable world.
📝 Dialogue system based on text files.
🛠️ Tools for validating and managing content.
🌐 Content that can be updated from GitHub.
