OBJETIVO DEL PROYECTO

Desarrollar un juego de rol 2D narrativo para Android orientado al aprendizaje de idiomas.

El aprendizaje debe estar integrado dentro de una aventura y no parecer un curso o un test.

El jugador aprenderá mediante:

* Contenido creado por el guionista.
* Comprensión de conversaciones.
* Decisiones durante la aventura.
* Consecuencias narrativas de las respuestas.

El objetivo inicial es conseguir una versión funcional con:

* Mapa 2D.
* Player.
* PNJ.
* Detección de proximidad.
* Conversaciones.
* Opciones.
* Progresión lingüística.
* XP.
* Inventario.
* Condiciones.
* Guardado.

+-- Sprite
|
+-- CollisionShape2D

El Player tiene movimiento básico y funciona correctamente.

PNJ

Tenemos una escena PNJ.

Su estructura es aproximadamente:

PNJ
|
+-- Sprite2D
|
+-- CollisionShape2D
|
+-- InteractionArea
|
+-- CollisionShape2D

InteractionArea es un Area2D.

No bloquea físicamente al Player.

DIALOGUEMANAGER

Tenemos:

DEFINICIÓN DE FINAL DE CONVERSACIÓN

Se ha decidido específicamente que llegar a [END] NO oculta la interfaz.

[END] es el último nodo del guion.

La sección END:

* Tiene texto.
* No tiene opciones.
* No muestra botones.
* Mantiene el diálogo visible.

La conversación permanece visible mientras el Player permanezca dentro de InteractionArea.

Cuando el Player sale de la zona del PNJ:

* Se termina la conversación.
* Se oculta DialogueUI.

Ejemplo:

[END]

La puerta se abre. Puedes pasar cuando quieras.

El texto permanece visible hasta que el Player se aleja.

[START]

¿Qué necesitas para abrir la puerta?

Eso no te ayudará a abrir la puerta.

FORMATO DE GUIÓN

El formato básico establecido es:

[START]

Texto.

Respuesta -> destino

[etiqueta]

Texto.

Respuesta -> destino

[END]

Texto final.

Los nodos utilizan etiquetas:

[START]
[LLAVE]
[END]

Las opciones utilizan:

Texto de respuesta -> destino

PARSER

Se acaba de crear:

res://scripts/dialogue_parser.gd

El parser actualmente interpreta:

* Etiquetas.
* Texto.
* Opciones con ->.
* START.
* END.
* Nodos intermedios.

Todavía NO interpreta:

* XP.
* Inventario.
* Condiciones.
* Efectos.

El parser devuelve una estructura tipo Dictionary que conceptualmente tiene:

START
|
+-- text
|
+-- options

LLAVE
|
+-- text
|
+-- options

END
|
+-- text
|
+-- options vacías

El parser ya está creado, pero todavía NO está conectado al DialogueManager.

IMPORTANTE

Actualmente el sistema está en una fase intermedia.

La interfaz y la lógica de navegación se probaron anteriormente utilizando dialogue_data escrito directamente en GDScript.

Después se decidió eliminar ese diálogo hardcodeado y empezar a utilizar TXT.

Ahora ya conseguimos:

1. El PNJ detecta al Player.
2. Se inicia la conversación.
3. DialogueManager localiza el TXT.
4. Godot abre el TXT.
5. Godot puede leer su contenido.
6. El parser ya está creado para interpretar el contenido.

Falta conectar el parser con DialogueManager.
